Add a Forecast section as a new planning-only module.

Important:
There is no active Forecast section in this uploaded codebase, so create it cleanly without touching Orders, Inventory, Production, Traceability, Packing, Labels, or Invoicing logic.

Goal:
Allow potential orders to be entered, estimate required stock/materials, and convert forecasts into true orders later.

Business rule:
Forecast = what we might need.
Order = what we must supply.
Inventory = only changes from real activity.

Core rules:
- Forecasts must not reduce stock.
- Forecasts must not create stock movements.
- Forecasts must not create invoices.
- Forecasts must not affect traceability.
- Forecasts must not reserve inventory.
- Forecasts are planning only until converted.
- Conversion should use the existing order creation logic where possible.
- After conversion, mark forecast as Converted so it is not double-counted.
