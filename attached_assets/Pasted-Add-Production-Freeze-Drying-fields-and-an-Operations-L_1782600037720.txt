Goal:
Capture simple freeze drying details during Production completion and provide one central place to review production notes, product assessments, and drying issues.

Part 1 — Production completion fields

Add these fields to production batches/records:
- dryingTimeHours decimal nullable
- dryingMachine text nullable
- dryingExtensionRequired boolean default false
- dryingExtensionTimeHours decimal nullable
- dryingNotes text nullable
- finalComments text nullable

Use existing productAssessment field if it already exists.
Do not duplicate productAssessment if already present.

Show these fields in the existing Manage Outputs / Complete Production workflow.

Keep it simple for staff:
- Drying Time Hours
- Machine
- Extension Required
- Extension Time Hours, only if extension required
- Drying Notes
- Product Assessment
- Final Comments

Rules:
- Drying time is manually entered only.
- Do not add drying start time or drying finish time yet.
- All fields are optional except where existing completion rules already require data.
- Store drying time and extension time as numbers.
- Store notes as text.

Display:
- Show drying time, machine, extension info, drying notes, product assessment, and final comments on the batch/production detail view.
- Show drying time on production cards/list if practical.

Part 2 — Operations Log

Add a new Operations Log section.

Purpose:
Central review page for all important operational notes and observations.

Initial source:
Production completion only.

When a production batch is completed or updated, automatically create Operations Log entries for:
- dryingNotes
- productAssessment
- finalComments
- dryingExtensionRequired / dryingExtensionTimeHours if applicable

Do not create duplicate log entries every time the same record is saved.
Update existing linked log entries when the production record notes are edited.

- createdAt
- updatedAt

Severity values:
